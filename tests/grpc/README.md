# gRPC smoke tests

**[Русская версия](README.ru.md)**

These smoke checks run without coordinator and validate agent behavior directly via `grpcurl`.

## Commands

From repository root:

```bash
task run:test
```

Runs agent with local test config and local certs.

```bash
task test:smoke
```

Requires a running test agent (`task run:test` in another terminal). Runs 3 `grpcurl` checks; optional report files under `tests/grpc/reports/` (gitignored): `runchecks-valid.out`, `runchecks-invalid-token.out`, `runchecks-invalid-payload.out`.

## Real request flow

To run one request generated by real coordinator logic, dump it in [mytonprovider-backend](https://github.com/mytonprovider/mytonprovider-backend) and copy the JSON here as `tests/grpc/runchecks-live.json` (with `runchecks-live-meta.json` next to it, if you want geo in the summary).

```bash
task run:test
```

In another terminal:

```bash
task test:live:replay
```

This sends that JSON into agent `RunChecks` endpoint via `grpcurl`.

The dump is made by the coordinator tool `dump-runchecks` (in-memory or from Postgres); how to run it is described in [mytonprovider-backend](https://github.com/mytonprovider/mytonprovider-backend).

## RunStorageRates (provider GetStorageRates)

The agent binds a UDP **ADNL** listener for DHT + provider transport (default port `16167`, override with `AGENT_ADNL_PORT`; test task uses `36167` to avoid clashes with a local coordinator).

### Replay (same coordinator path as RunChecks)

`dump-runchecks` can also write **`runchecks-live-storage-rates.json`** (pubkeys taken from the built RunChecks payload, same order). Copy it to `tests/grpc/` with `runchecks-live.json`, then with the test agent running (`task run:test`) run **`task test:live:storage-rates:replay`** — `grpcurl` to `RunStorageRates`; last response is saved under `tests/grpc/reports/runchecks-storage-rates-last.json`.

Example `grpcurl` (replace `PROVIDER_PUBKEY_HEX64` with a real 64-char hex pubkey):

```bash
grpcurl -insecure \
  -import-path contracts/proto \
  -proto providerchecks/v1/provider_checks.proto \
  -H "authorization: Bearer test-token" \
  -d '{"jobId":"rates-smoke-1","providerPubkeys":["PROVIDER_PUBKEY_HEX64"],"querySize":1,"timeouts":{"queryTimeoutMs":14000,"totalMs":60000}}' \
  127.0.0.1:8443 \
  providerchecks.v1.ProviderChecksService/RunStorageRates
```

## Prerequisites

- `grpcurl` installed and available in `PATH`
- `openssl` installed
- For default live dump: outbound network to TON lite servers / config URL
- For `--storage=postgres`: Postgres with coordinator schema
